# xEMMWORK

The portfolio of EMM (studio Emmency): brand identities, websites, logos, posters and graphic design.
Live at **https://xemmwork.vercel.app**.

Built with React 19, Vite, Tailwind CSS 4, Base UI and cmdk.

## A few details

- **Dither.** Ordered Bayer 4×4 tiles in 2px pixels, used as CSS masks (`src/index.css`). The same tiles drive
  the hover crawl on buttons and cards, images developing in as they load, and the page change between home and
  a case study (View Transitions API). A fade is always a run of dither levels, never a gradient.
- **Websites.** `src/components/websites.tsx`: a compare slider (pointer capture, touch-friendly, keyboard
  operable as a slider) and a live mode that runs the real site at a true desktop or phone width, scaled to fit.
- **⌘K / Ctrl+K or `/`.** `src/components/command.tsx`: jump to any section, brand, poster or graphic.
- **Respectful by default.** `prefers-reduced-motion` turns the motion off; every hover state also works with
  keyboard focus; light and dark themes.

## Run it

```bash
npm install
npm run dev     # http://localhost:5173
npm run build   # one self-contained index.html, written to ../website
```

The content in `src/content.json` and the images in `public/work` are generated by a private curation script.
